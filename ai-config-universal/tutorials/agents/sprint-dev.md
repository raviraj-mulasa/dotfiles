# Sprint-Dev Agent — Tutorial

**Tier:** ⚪ Team / Sprint Orchestration
**Type:** Agent (executes sprint bricks)
**Full agent:** `agents/sprint-dev.md`

---

## What It Does

Specialized builder agent that implements isolated "bricks" (tasks) during multi-agent sprint execution. Before writing a single line of code, it analyzes the spec and design documents, identifies missing details or contradictions, and flags gaps rather than guessing.

---

## When to Use It

- Executing task bricks generated by the `sprint` skill (`skills/sprint/SKILL.md`)
- Working on features decomposed into parallel workstreams
- When you want built-in gap detection before implementation starts

---

## How to Invoke

**Copilot Chat:**
```
@workspace Act as the sprint-dev agent defined in agents/sprint-dev.md.
Read docs/specs/auth.spec.md and implement Brick 002: Token Refresh Endpoint.
```

**Claude Code:**
```
Use the sprint-dev agent to build Brick 003 using the design in tasks/billing.design.md
```

**AGY:** "Implement sprint brick...", "sprint dev for brick..."

---

## Operating Rules

1. **Read sources of truth first**: Always review spec, contracts, and design docs before coding.
2. **Report gaps before building**: If a parameter or error state is unspecified, ask first.
3. **Adhere strictly to public contracts**: Do not deviate from defined schemas.
